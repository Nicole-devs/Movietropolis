# Movietropolis Movie App

A sleek, modern web application for streaming movies and TV shows. This app fetches data from The Movie Database (TMDb) API and displays popular movies and TV shows in a responsive layout.

## Features

- **Featured Slider:** See featured movies on the home page.
- **Dynamic Details Pages:** Get in-depth information about each movie or TV show.
- **Interactive Search:** Easily search for movies and TV shows.
- **Modern UI:** Enjoy a clean and intuitive user interface.

## Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/yourusername/movietropolis.git
   ```

2. **Navigate to the project directory:**

   ```bash
   cd movietropolis
   ```

3. **Open index.html in you browser**

   Simply open the index.html file in your preferred web browser to see the app in action.

## Technologies Used

- HTML, CSS, JavaScript
- TMDb API: To retrieve movie and TV show data.
- Responsive Design: Ensuring a smooth experience on any device.
- Font Awesome: For sleek iconography.
